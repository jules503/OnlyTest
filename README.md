Вёрстка и анимация лендинга по макету. Десктопная версия.

Стек: Pug, SCSS, TypeScript, Vite, GSAP.

## Запуск

Нужен Node.js 20.19 или новее.

**Шаг 1.** Установить зависимости — один раз после скачивания проекта:

```bash
npm install
```

**Шаг 2.** Запустить дев-сервер:

```bash
npm run dev
```

Проект откроется на `http://localhost:5173`. Этого достаточно, чтобы посмотреть работу.

## Сборка

Если нужна продакшен-версия, вместо шага 2:

```bash
npm run build    # соберёт в папку dist
npm run preview  # покажет собранное на локальном сервере
```

`npm run preview` работает только после `npm run build`.

---

Разметка находится в `src/index.pug`. Файл `index.html` — заглушка для Vite,
его содержимое подставляется при сборке.
